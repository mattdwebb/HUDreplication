This folder contains all files needed to automatically generate the comparison tables.

All input files are provided in the following folders:
  - "templates"
  - "stata_pooled" 
  - "stata_matched_pairs"

A set of julia program and modules are provided. To start:
  - run "makeComparisonTables.jl" and follow the instructions

All outputs are provided as a reference in the following folders:
  - "REFERENCE_temp_tables"
  - "REFERENCE_output_tables"
